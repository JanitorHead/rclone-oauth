Privacy policy

Last updated: 2026-10-12

This OAuth client is used by its owner only, to run rclone against the owner's own Google Drive.

What data it accesses

It reads and writes files in the owner's Google Drive. Those files are a backup repository that is encrypted before it is uploaded.

What it does with the data

It only copies the backup to Google Drive and back. It does not collect, sell, share or analyse any data. No data goes to third parties, and nothing is used for advertising.

Where the credentials live

The OAuth token is stored only on the owner's own server. Access can be revoked at any time from the Google account's security settings (Third-party apps with account access).
